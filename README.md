# Runtime Components

This repo contains my personal runtime configurations files (rc files) which I could quickly use to set up my development environment on a new machine. 

## Included Components

- `.bashrc` - Bash shell configuration
- `.zshrc` - Zsh shell configuration for Mac terminal
- `.vimrc` - Vim editor configuration
- `.gitconfig` - Git configuration settings
- `.gdbinit` - GDB debugger configuration
- `install.sh` - Script to install runtime components automatically
